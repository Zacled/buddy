How do these virtual dice work?

This website uses virtual dice created with an algorithm that assigns equal probabilities to every possible outcome. By clicking the Roll Again! button you can re-roll all the dice on this page.

Choose between 1 and 100 dice, each with 6 sides and 6 possible colors:
Red, Orange, Yellow, Green, Blue and Purple.

About us

This is a free online dice simulator anyone can use to roll virtual dice when no real dice are available. Use it for board games, online games, or any other game of chance — right from your browser, no installation required.
