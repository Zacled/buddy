How do these virtual dice work?

This website uses virtual dice created with an algorithm that assigns equal probabilities to every possible outcome. By clicking on the 'Roll Again' button you can re-roll all the dice on this page.

This page allows you to choose any number of dice between 1 and 100, as well as the types of dice used (d4, d6, d8, d10, d12 and d20). Simply use the drop-down menu above to select the dice you wish to use for your next roll.

About us

Online-Dice is an online dice simulator that anyone can use to roll virtual dice when no real dice are available. With this free simulator you can roll dice for online games, board games, or any other game of chance.
