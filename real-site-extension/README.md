# Wheel Picker

A tiny Chrome extension for **wheelofnames.com**. Press a number key and the wheel
lands on that name — but at a random spot inside the slice, so it stops somewhere
different every spin.

## Install
1. Unzip this folder.
2. Go to `chrome://extensions`, turn on **Developer mode** (top-right).
3. Click **Load unpacked** and select this folder.
   (After updating the files, click the **reload ↻** icon on the card, then refresh
   any open wheelofnames.com tab.)

## Use
On wheelofnames.com:
- **1–9** → that position wins (1 = first name in the list).
- **0** or **Esc** → back to a fair spin.
- Spin the wheel (click it). The toolbar badge shows the armed number.

The popup has an on/off switch and a status line. Under **Advanced** there's an
"Aim offset" — only touch it if a spin ever lands one name off (nudge it up/down
by 0.005 until it lands right; **reset to 0.363** undoes it).

Everything is local to your browser. No accounts, no codes.
